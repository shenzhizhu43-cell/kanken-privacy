# セーフサイン プライバシーポリシー

最終更新: 2026-06-11 / ステータス: **ドラフト（ホスティングしてURL化が必要）**

> Chrome Web Store 公開にはプライバシーポリシーURLの掲示が必要。
> 本拡張は外部送信・収集を一切行わない設計のため、その旨を明確に記載する。
> 公開時は `privacy-policy.html` をホスティング（案件ガードと同じ GitHub Pages リポジトリにページ追加が手軽）してURLをストア掲載情報に登録する。

---

## 1. 基本方針
セーフサイン（以下「本拡張」）は、利用者のプライバシーを最優先します。
本拡張は、**利用者が入力・選択した文章やページ内容を外部に送信・収集・保存・販売しません**。

## 2. 取り扱う情報と処理の場所
- 本拡張は、利用者が**入力欄に貼り付けた文章**、または「選択範囲を取り込む」操作で取得した**選択テキスト**を読み取り、危険信号をルールベースで判定します。
- これらの**判定処理はすべて利用者のブラウザ内（ローカル）で完結**します。
- 読み取った文章を、外部サーバー・第三者・開発者へ送信することは**一切ありません**。
- 本拡張は外部API・アナリティクス・トラッキングを使用しません。入力文の保存も行いません（判定後に保持しません）。

## 3. 権限について
- `activeTab`: 「選択範囲を取り込む」ボタンを押したときに限り、現在のタブの選択テキストを取得するため。
- `scripting`: 上記の選択テキストを読み取る最小スクリプトを実行するため。
- これらの権限は、データを外部に送る目的では使用しません。常時のページ監視・閲覧履歴の取得は行いません。

## 4. 第三者提供・広告
- 第三者へのデータ提供、広告配信、行動追跡は行いません。

## 5. 免責
- 本拡張の判定は**ルールベースの注意喚起の補助**であり、案件や文章の安全性を保証するものではありません。
- 最終的な応募・契約・連絡の判断は利用者ご自身の責任で行ってください。
