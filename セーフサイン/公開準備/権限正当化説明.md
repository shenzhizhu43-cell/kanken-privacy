# 権限の正当化説明（Chrome Web Store 申請用）

対象拡張: セーフサイン v1.0.0
用途: Chrome Web Store ダッシュボードの「権限の正当化（permission justification）」欄に転記する下書き
最終更新: 2026-06-11

> 記載は manifest.json v1.0.0 の宣言と一致。宣言しているのは `permissions: ["activeTab", "scripting"]` のみ。
> host_permissions・content_scripts・background/service_worker・storage は宣言していません。

---

## Single purpose（拡張の単一目的）

この拡張機能の唯一の目的は、利用者が貼り付けた（またはページ上で選択した）募集文・仕事の説明文から、詐欺・闇バイト・規約違反などの危険信号をルールベースで検出し、安全度を信号機（赤/黄/緑）で表示して注意喚起することです。

判定はすべて利用者のブラウザ内（ローカル）で完結します。入力された文章を外部サーバー・第三者・開発者へ送信したり収集したりすることは一切なく、外部API・アナリティクス・広告・トラッキングも使用しません。動作は文章の読み取りと判定結果の画面表示のみで、閲覧中ページの内容を改変・送信することはありません。

---

## 各権限の正当化

### permissions: `activeTab`

- なぜ必要か: 「ページの選択範囲を取り込む」ボタンを押したときに限り、現在表示しているタブで利用者が選択しているテキストを取得するため。
- 何に使うか: 利用者の明示的なボタン操作に応じて、アクティブなタブの選択テキストを読み取り、判定用のテキスト欄に取り込む。
- 何に使わないか: 常時のページ監視、閲覧履歴の取得、全サイトへの恒常的アクセスは行いません。ボタンを押さない限りページに触れません。外部送信もしません。

### permissions: `scripting`

- なぜ必要か: 上記の選択テキスト取得のため、ボタン押下時にアクティブタブへ「選択範囲の文字列を返す」最小スクリプト（`window.getSelection().toString()` 相当）を一度だけ実行するため。
- 何に使うか: 選択テキストの読み取りのみ。
- 何に使わないか: ページDOMの改変、フォーム送信、データの外部送信は行いません。実行はユーザー操作時の単発のみで、コードは拡張に同梱（リモートコードの読み込みなし）。

---

## 補足（審査担当者向けの要点）

- 宣言権限は `activeTab` と `scripting` の2つのみ。host_permissions やブロードホストアクセスは要求していません。動作の起点は常に利用者のボタン操作です。
- リモートコードの読み込みはありません。検出ルールは拡張内に同梱した JavaScript（ルールベース）で、外部API・リモートスクリプトを呼び出しません。
- データ収集・外部送信・トラッキング・広告は一切なく、すべての処理はブラウザ内で完結します（プライバシーポリシーに記載）。
- 本拡張は注意喚起の補助ツールであり、判定の正確性や案件の安全性を保証するものではありません。
