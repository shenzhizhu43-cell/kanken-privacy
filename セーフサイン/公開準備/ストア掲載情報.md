## 1. カテゴリ
- 仕事効率化（Productivity）

## 2. 簡単な説明（132文字以内）
> 募集文や仕事の説明をコピペするだけで、詐欺・闇バイト・規約違反などの危険信号をその場でチェック。安全度を赤・黄・緑の信号で表示します。判定は端末内で完結し、入力した文章を外部に送信しません。無料。

## 3. 詳細な説明（本文案）
```
■ こんな方へ
・副業やバイトの募集を見て「これ大丈夫？」と不安になることがある
・「前払い」「LINE登録」「簡単に高収入」などの文句に迷ったことがある
・闇バイトや詐欺案件を、応募する前にサッと見分けたい

■ できること
・募集文や仕事の説明文を貼り付けるだけで危険信号を自動チェック
  例）登録料・教材費などの前払い要求、口座/名義貸し・受け取り代行（闇バイト）、
      契約前の身分証・口座要求、やらせレビュー等の規約違反、
      LINE等の外部誘導、うますぎる誘い文句、極端な低単価、連絡先の直書き
・赤(危険)・黄(注意)・緑(安全)の信号で安全度をひと目で表示
・該当した項目ごとに「なぜ危険か」「どうすべきか」を表示
・ページ上で文章を選択して取り込むこともできます

■ プライバシー
・判定はすべてあなたのブラウザ内で完結します
・入力した文章やページ内容を外部に送信・収集することは一切ありません
・広告・トラッキングなし

■ ご注意
・本拡張はルールベースの簡易チェックで、注意喚起の補助ツールです。
・判定は目安であり、安全を保証するものではありません。最終判断はご自身で行ってください。
```

## 4. 必要なアセット
- アイコン: 128px（作成済み: `icons/icon128.png` 信号機モチーフ）
- スクリーンショット: 1280×800 もしくは 640×400、最低1枚（最大5枚推奨）
  - 案①: 詐欺文を貼って「危険(赤)」＋該当項目リスト表示
  - 案②: 注意レベル(黄)の例（低単価＋連絡先直書き 等）
  - 案③: 正常な募集文で「安全(緑)」
  - マスク: ダミー文を使用（実在の募集・個人情報は載せない）
- （任意）小さなプロモタイル 440×280
