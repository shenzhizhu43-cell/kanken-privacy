# セーフサイン

募集文・仕事の文章を貼り付けるだけで、危険信号をその場で判定し**信号機（赤/黄/緑）で安全度を表示**する無料Chrome拡張。
案件ガードと同じ**ルールベース・API不要・端末内完結**（外部送信なし）の路線。一般ユーザー向けに対象を広げた第3弾。

## 立ち位置
- 案件ガード（第1弾・公開済）＝クラウドソーシングの発注者リスク判定（サイト連動）
- セーフサイン（本拡張）＝**任意の募集/仕事文をコピペ判定**。詐欺・闇バイト・規約違反の一次フィルタ

## 構成（Manifest V3）
- `manifest.json` … ポップアップ型。権限は `activeTab` `scripting` のみ（最小）
- `popup.html` / `popup.css` / `popup.js` … UI・選択範囲取り込み・Cmd+Enter判定
- `rules.js` … 判定エンジン（独立ファイル＝単体検証可能）
- `icons/` … icon16/48/128（信号機モチーフ・PILで生成）

## 判定ロジック（rules.js）
8ルール = high(赤)4種 / mid(黄)4種。
- high: 前払い・金銭要求 / 名義貸し・受け取り代行(闇バイト) / 個人情報・口座の早期要求 / 規約違反・不正
- mid : 外部サービス誘導(LINE等) / うますぎる誘い文句 / 極端な低単価 / 連絡先の直書き
- 総合判定: high≥1 or mid≥3 → **危険** ／ mid≥1 → **注意** ／ それ以外 → 安全(30字未満は情報不足)
